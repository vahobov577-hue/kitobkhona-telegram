# Китобхона для Telegram: инструкция по запуску

## Что внутри
- `index.html` — само приложение (Mini App): читалка, ИИ-репетитор, карточки, экзамен, вазифа бо расм, заметки, статистика.
- `main.py` — сервер и бот в одном процессе:
  - бот: `/start` (кнопка «Китобхонаро кушодан»), `/pro` (оплата Telegram Stars), кнопка меню в чате;
  - `/api/ai` — прокси к Claude (ключ хранится только на сервере; есть дневные лимиты);
  - `/api/state` — синхронизация прогресса между устройствами по аккаунту Telegram;
  - `/api/invoice` — счёт на Pro в Stars.
- `books/` — сюда кладите PDF книг, на которые у вас есть права.
- `requirements.txt`, `Dockerfile`, `.env.example`.

## Что нужно
1. **Бот** от @BotFather (`/newbot`) и его токен. Если бот уже есть, берите его токен.
2. **Ключ Anthropic API** (console.anthropic.com). За запросы ИИ платите вы. Поставьте месячный лимит расходов в консоли.
3. **Сервер с HTTPS.** Telegram открывает Mini App только по https. Варианты: Render, Railway, Fly.io (есть бесплатные/дешёвые тарифы) или свой VPS.

## Запуск
1. Скопируйте `.env.example` в `.env` и заполните (`BOT_TOKEN`, `ANTHROPIC_API_KEY`, `WEBAPP_URL`).
2. Локально:
   ```
   pip install -r requirements.txt
   export $(cat .env | xargs)      # Windows: задайте переменные вручную
   uvicorn main:app --host 0.0.0.0 --port 8000
   ```
   Для проверки с телефона сделайте временную https-ссылку: `cloudflared tunnel --url http://localhost:8000` (или ngrok) и подставьте её в `WEBAPP_URL`.
3. На хостинге: загрузите папку, задайте те же переменные окружения, команда запуска из `Dockerfile` (или `uvicorn main:app --host 0.0.0.0 --port $PORT`).
4. Откройте бота в Telegram → `/start` → кнопка. При старте сервер сам ставит кнопку меню бота.

## Книги
Приложение по умолчанию показывает только демо-книги. Чтобы добавить свои:
1. Положите PDF в `books/`, например `books/adabiyot.pdf`.
2. В `index.html` найдите `BOOK_URLS` и впишите путь: `{5:"books/adabiyot.pdf", ...}` (номера 5–9 это учебники из прототипа; для новых книг добавьте запись в `BOOKS` по образцу).
3. **Права.** Публиковать и продавать можно только книги из общественного достояния или с разрешением правообладателя. Школьные учебники издательства «Маориф» без разрешения в публичный бот не добавляйте.

## Оплата и лимиты
- Подписка идёт через Telegram Stars (для цифровых товаров это требование Telegram). Цена в `PRO_STARS`.
- Бесплатно: `FREE_AI_PER_DAY` запросов ИИ в день, Pro: `PRO_AI_PER_DAY`. Следите за расходами на API.
- База (`data.db`) хранит Pro-доступ, лимиты и прогресс. Делайте её резервные копии. На бесплатных хостингах диск может стираться, подключите постоянный диск.

- В Telegram ответы ИИ приходят целиком, а не печатаются по буквам.

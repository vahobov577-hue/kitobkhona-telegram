# Сайт «Родничок» · ООО «Шарбати Мева»

Одностраничный сайт производителя воды, соков, лимонадов и консервации (Палас, Таджикистан, +992 92 842 00 88).
Обычный статический сайт без сборки: его можно залить на любой хостинг (Netlify, Vercel, GitHub Pages, cPanel).

## Запуск локально
```bash
cd rodnichok-site
python3 -m http.server 8000   # затем откройте http://localhost:8000
```

## Анимации и технологии
- **Прелоадер**: логотип наполняется водой с бегущей волной, потом раскрывается кругом.
- **Hero на WebGL**: собственный шейдер каустики (свет на дне родника). От курсора идёт рябь, от клика расходятся кольца. Разрешение снижается само, если устройство слабое.
- **Кинетическая типографика**: буквы «Родничок» выпрыгивают, покачиваются на воде и расступаются от курсора.
- **Две ленты-бегущие строки**: скорость и направление зависят от того, как пользователь крутит страницу.
- **Манифест**: слова проявляются, в тексте раскрываются капсулы с фото.
- **Горизонтальная лента продуктов**: фон перетекает в цвет каждой линейки, фото наклоняются от скорости прокрутки, внутри фото работает параллакс, на фото есть 3D-наклон.
- **Путь капли**: SVG-змейка строится под размер экрана, капля едет по ней.
- **Одометр**: цифры прокручиваются как в счётчике.
- **Награды**: колода раскладывается веером, у карточек 3D-наклон и блик.
- **Производство**: окно с фото раскрывается на весь экран.
- **Кнопки**: магнитные, заливка растекается от точки, где в кнопку вошёл курсор.
- **Подвал**: живые волны. Бутылка в углу заполняется по мере прокрутки.
- Плавный скролл **Lenis**, зернистость плёнки, поддержка `prefers-reduced-motion`, отдельная мобильная версия.

Стек: GSAP 3.12 + ScrollTrigger, Lenis, чистый WebGL, Canvas 2D. Библиотеки лежат в `assets/vendor`, поэтому от CDN сайт не зависит.

## Структура
```
index.html
assets/css/style.css
assets/js/main.js      — все анимации
assets/js/water.js     — WebGL-шейдер воды
assets/img/            — фото, сжатые в WebP, логотип с прозрачным фоном
assets/vendor/         — gsap, ScrollTrigger, lenis
```
